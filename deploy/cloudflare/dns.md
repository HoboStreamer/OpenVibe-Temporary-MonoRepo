# Cloudflare DNS guidance

Recommended DNS shape:

- `openvibe.network`
- `auth.openvibe.network`
- `admin.openvibe.network`
- `my.openvibe.network`
- `themes.openvibe.network`
- `openvibe.tools`
- `openvibe.live`
- `openre.stream`
- `openvibe.chat`
- `openvibe.community`
- `openvibe.media`
- `ai.openvibe.network`
- `openvibe.games`
- `openvibe.codes`
- `openvibe.blog`
- `openvibe.wiki`

Keep draft hosts (`openvibe.news`, `openvibe.reviews`, `openvibe.deals`, `openvibe.coupons`, `openvibe.trade`) pointed only when the origin is intentionally serving noindex placeholders or the production runtime is actually ready.
