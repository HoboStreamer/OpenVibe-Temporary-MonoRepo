openvibe-community

OpenVibe Phase 5 — spaces, threads, posts, pastes, Discord relay

This service owns shared discussion infrastructure: communities/spaces, categories, threads, posts, reusable comments (vods, clips, blog), pastes, and Discord channel relays.

API quick-reference

  • GET/POST /api/community/spaces
  • GET/POST /api/community/spaces/:id/categories
  • GET/POST /api/community/threads · /threads/:id/posts
  • GET/POST /api/community/comments?ref_type=&ref_id=
  • GET/POST /api/community/pastes (legacy /api/pastes/*)
  • POST /api/community/discord/webhook
