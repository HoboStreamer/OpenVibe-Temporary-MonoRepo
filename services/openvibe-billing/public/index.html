Payment methods

Accept money your way

The billing service ships with three payment providers out of the box. Each plugs into the same checkout session + webhook lifecycle.

💳

Stub (Dev/Test)

A simulated checkout for local development and integration tests. No real money moves. Enables full end-to-end testing without external credentials.

No API key Instant complete Always available
🅿️

PayPal

First-class PayPal Orders API v2 integration. Supports PayPal wallet, Venmo, and card payments via PayPal. Webhooks verify signatures with the PayPal SDK. Monthly / one-time supported.

PayPal Wallet Venmo Credit card
PAYPAL_CLIENT_ID PAYPAL_CLIENT_SECRET
₿

Crypto

Direct on-chain payments. Accepts Bitcoin, Ethereum, and USDC. Generates a unique deposit address per session and monitors for confirmations via configurable node or service URL.

Bitcoin (BTC) Ethereum (ETH) USDC
CRYPTO_RECEIVE_ADDR CRYPTO_NODE_URL
Products

Three surfaces, one ledger

All products share the same credits economy and atomic ledger. They're independently accessible via route prefix or custom hostname.

💰

Credits Ledger

Double-entry ledger with wallet snapshots, idempotent transactions, and reconciliation. Fund wallets via checkout, charge for platform actions, refund atomically.

GET  /api/billing/wallet/:type/:id
POST /api/billing/credits/checkout
POST /api/billing/credits/charge
POST /api/billing/credits/refund
GET  /api/billing/wallet/:type/:id/transactions
🎁

Tips

Audience-to-creator tipping with TTS and media-request lanes, real-time overlay feeds, customizable visibility, and side-effects to chat. Native free system — no third-party required.

POST /api/tips/create
GET  /api/tips/overlay/:type/:id
GET  /api/tips/creator/:type/:id
POST /api/tips/creators  (enroll)
⭐

VIP Plans

Creator-defined subscription plans with configurable perks, billing intervals, and entitlement propagation. Operators can freeze, admin can reconcile wallet snapshots.

POST /api/vip/plans
GET  /api/vip/plans/:id
POST /api/vip/subscriptions
POST /api/vip/subscriptions/:id/cancel
GET  /api/billing/entitlements/:type/:id
