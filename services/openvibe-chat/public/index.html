openvibe-chat

OpenVibe Phase 5 — chat / DMs / calls / TTS / audio

This is the admin landing page for the chat service. The canonical realtime UI lives in openvibe-live (stream chat + overlays) and HoboStreamer compat surfaces. This service exposes a REST + future WebSocket API at /api/chat/*.

API quick-reference

  • GET /api/chat/rooms · POST /api/chat/rooms
  • GET/POST /api/chat/rooms/:id/messages
  • GET/POST /api/chat/global/{history,send}
  • GET/POST /api/chat/stream/:streamId/{history,send}
  • GET/POST /api/chat/dms · GET/POST /api/chat/dms/:roomId/messages
  • POST /api/chat/calls, /calls/:id/{accept,decline,end,signal}
  • GET/PUT /api/chat/tts/settings · POST /api/chat/tts/queue
  • POST /api/chat/audio/queue · POST /api/chat/audio/resolve-external
