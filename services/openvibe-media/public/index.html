OpenVibe Media

This service owns shared media object storage, processing, quotas, and the media.events bus topic for the OpenVibe network.

Routes:

  • POST /api/v1/media/upload/init
  • PUT /api/v1/media/:id/upload (multipart file)
  • POST /api/v1/media/:id/upload/complete
  • GET /api/v1/media/:id
  • GET /api/v1/media?namespace=…&owner_type=…&owner_id=…
  • DELETE /api/v1/media/:id
  • GET /api/v1/quota?namespace=…&owner_type=…&owner_id=…
  • GET /api/v1/admin/jobs
  • GET /files/:id — visibility-checked file serve

See README.md for full validation steps.
