Storage notes

A quick reminder of what this surface is exercising right now.

  • Uploads bootstrap through the public media API and only succeed when the caller has valid auth.
  • Quota inspection is intentionally owner-scoped so the shell does not guess identity context and lie about limits.
  • Recent objects come from the same shared store used by clips, avatars, paste attachments, and migration backfill.
