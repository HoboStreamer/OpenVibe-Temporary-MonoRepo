What the network promises

No investors, no ad surveillance, no premium-tier theatre. The plan is to be useful and to formalize as a not-for-profit once the network can stand on its own.

Open source

Every surface can be inspected, forked, or self-hosted

No mystery SaaS layer. Registries, auth, chat, live, media, billing, and migration tooling all live in public code with predictable contracts. If we disappeared tomorrow, you could keep running it.

Portable identity

Your @username, theme, and launcher state travel with you

The control plane stores account preferences in explicit user-module namespaces — no vague session magic, no "we lost your settings on the redesign".

No ads, no tracking

Anonymous mode is one click away

No behavioral ads, no surprise beacons, no surveillance glitter. Switch to an anonymous identity any time — your data stays yours by default, not as a premium feature.

Composable platform

Contracts, topics, and capabilities are first-class

It is easier to build on a network when the network can explain itself. The registry pulse above is not just pretty chrome — it is runtime truth.

Not-for-profit plan

Built to be sustainable, not extractive

Tips and VIP exist so creators get paid and servers stay online — not so we can carve features out of the platform and resell them. The long game is a real public-benefit project, not an exit.
